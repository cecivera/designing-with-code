# Foundations

**Tokens** are named design decisions: colors, radii and typography. In this project they live as **CSS variables** in
`src/app/globals.css`, and Tailwind turns them into classes (`bg-primary`, `text-muted-foreground`, `rounded-lg`…).

- `:root` block → **light mode** values (the ones you see on this page and across Storybook).
- `@theme inline` block → connects each variable to Tailwind (`--color-primary: var(--primary)`).
- Project rule: **never hardcode colors**; always use the token (`bg-primary`, not `bg-[#171717]`).

> Each swatch reads its value live from the CSS, so if you change `globals.css` this page updates automatically.
> Color format: [OKLCH](https://oklch.com) (lightness, chroma, hue).

## Radius (border-radius)

All radii come from a single variable, `--radius`. Changing it changes the corners across the whole system.

<Unstyled>
  <RadiusScale />
</Unstyled>

> **Note:** `evergreen-brand.css` forces **radius 0** (square corners) on Button, Card, Badge, Input, Textarea, Dialog and Sheet as a brand decision.
> That's why those components look square even though `--radius` is `0.625rem`.

## Typography

The font is **Geist** (by Vercel). In the app it's loaded by `next/font` in `src/app/layout.tsx`; in Storybook it's loaded from the `geist` package (`.storybook/preview.css`).
Tailwind exposes it as `font-sans` and `font-mono`.
