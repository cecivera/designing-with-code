# Fundamentos

Los **tokens** son las decisiones de diseño con nombre: colores, radios y tipografía. En este proyecto viven como **variables CSS** en
`src/app/globals.css` y Tailwind las convierte en clases (`bg-primary`, `text-muted-foreground`, `rounded-lg`…).

- Bloque `:root` → valores del **modo claro** (los que ves en esta página y en todo Storybook).
- Bloque `@theme inline` → conecta cada variable con Tailwind (`--color-primary: var(--primary)`).
- Regla del proyecto: **nunca colores a mano**; usa siempre el token (`bg-primary`, no `bg-[#171717]`).

> Los valores de cada muestra se leen en directo del CSS, así que si cambias `globals.css` esta página se actualiza sola.
> Formato de color: [OKLCH](https://oklch.com) (luminosidad, croma, tono).

## Radio (border-radius)

Todos los radios salen de una sola variable, `--radius`. Cambiándola cambias las esquinas de todo el sistema.

<Unstyled>
  <RadiusScale />
</Unstyled>

> **Ojo:** `evergreen-brand.css` fuerza **radio 0** (esquinas rectas) en Button, Card, Badge, Input, Textarea, Dialog y Sheet como decisión de marca.
> Por eso esos componentes se ven rectos aunque `--radius` sea `0.625rem`.

## Tipografía

La fuente es **Geist** (de Vercel). En la app la carga `next/font` en `src/app/layout.tsx`; en Storybook se carga desde el paquete `geist` (`.storybook/preview.css`).
Tailwind la expone como `font-sans` y `font-mono`.

<Unstyled>
  <FontSpecimen family="sans" variable="--font-geist-sans" />
  <FontSpecimen family="mono" variable="--font-geist-mono" />
</Unstyled>
